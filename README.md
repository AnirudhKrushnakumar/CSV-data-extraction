# How to Use:
 Clone this repo and open it using your code editor of choice (VSCode is recommended). Within the project folder, the .csv file and two .py files can be found. 'robot_sensor_analyzer.py' can be used by simply just running through the terminal, and will go through 'Robot_Sensor_Readings_1000' for it's data. 'dataset_test.py' also runs via terminal, but is does not need another file to operate.
